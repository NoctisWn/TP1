Descripción de la Actividad

Desarrollo de un script en PowerShell para consultar de forma automatizada la versión de PowerShell, la política de ejecución vigente, la información del sistema operativo y los datos generales del equipo mediante comandos del sistema.

Comandos Principales Utilizados

  • $PSVersionTable → Información general de PowerShell
  • $PSVersionTable.PSVersion → Versión exacta instalada
  • Get-ExecutionPolicy → Política de ejecución actual del entorno
  • Get-CimInstance Win32_OperatingSystem → Información detallada del sistema operativo
  • systeminfo → Información general y extendida del equipo mediante CMD

Cómo ejecutar el script

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
.\info_sistema.ps1
